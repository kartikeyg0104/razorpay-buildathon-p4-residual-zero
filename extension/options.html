Extension options

Desk endpoint and token

Point the extension at your Residual Zero desk. A deployed desk must be https://; a loopback development desk is also accepted.

To get a token: open the desk in a browser, sign in, visit /tokens, create one, and paste it below. The token carries your own permissions and nothing more — no role in Residual Zero can authorise a clear.

What this extension holds

No API keys. No database credentials. The NVIDIA model is called on the server and its key never reaches the browser. The only credential stored here is your own access token, kept in this browser's extension storage and sent only to the desk URL above.

Safety

This extension is read-only. It renders results the deterministic engine produced and can never write CLEARED, resolve an exception, or change engine state.
